# Korean Blog Reference Structure

## Canonical reference

```text
https://blog.ponslink.com/writing/2026-06-16-ponslink-01-why-i-came-back-to-connection
```

## Reference shape, not a fixed template

1. **Opening:** use 2–4 prose paragraphs before an image or `##` when the chosen genre needs a scene. A short note may begin more directly.
   - concrete discomfort, observation, or question when applicable
   - first wrong assumption when the source has one
   - real tension or stake without a textbook definition
2. **Body:** the smallest complete set of topic-specific sections; merge sections that repeat evidence.
3. **Close:** use final `## 마치며` for retrospective posts unless the user explicitly requests another editorial form.
4. **Images:** use only distinct body WebP assets that clarify the story; typically 2–3, never duplicated to satisfy a count.
5. **Length:** ~1,200–3,500 hangul when supported; never pad and never impose a floor.
6. **Cadence:** retrospective paragraphs with natural variation. Avoid poetic single-line stacks, but do not force every paragraph to the same length.

## Banned H2 templates

`한 줄`, `현장에서 먼저 터진 증상`, `그럴듯해 보였던 첫 설계`, `로그가 말해 준 반례`,
`책임을 옮긴 경계선`, `운영에서 고정한 규칙`, `이 판단이 제품 문장으로 남는 방식`,
`현장 기준으로 다시 고정하는 원칙`, `운영 체크리스트`, bare `개요`/`구현`/`결론`

## Series rule

Each post needs its own H2 wording derived from its title tension.
Sibling posts must not share the same ordered H2 signature.
